# Fonts

The browser interface embeds two variable fonts, both under the SIL Open Font License 1.1 (see the license files here):

- JetBrains Mono, for source text and the interface: `mono*.woff2`
- IBM Plex Sans, for comments and the Markdown preview: `sans*.woff2`

The files are the Latin and Latin Extended subsets of the `@fontsource-variable/jetbrains-mono` and `@fontsource-variable/ibm-plex-sans` packages, version 5.3.0. Browsers download a file only when the page uses its characters and style.
